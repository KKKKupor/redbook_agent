# Generator — 测试题生成

**角色**: 心理测评量表设计师  
**Temperature**: 0.85  
**模型**: DeepSeek-Chat (max_tokens=16384)  

## 2026-08-25 变更
- **评分对抗性设计**(skill 分值标注段重写,响应"分数低且维度分布相近"反馈):
  - 每个选项只对 1-2 个核心维度打正分、其余一律 0(原"2-4 个维度得正分"让总分趋同)
  - 对抗性锚定:每题考察的每个维度至少一个选项给满分 max_score、一个给 0
  - 分值自检升级:维度总可达分均衡 + 预期最高/最低维度差 ≥20/100

## 2026-08-10 变更
- **动态评分**: `max_score = round(100/question_count)`，每题分值上限随题量自动调整。10题→max=10，50题→max=2。最终得分自然趋近0-100
- **校验自适应**: `_validate_questions` 的合法分值范围从硬编码[0,3]改为传入`max_score`参数
- **Skill增强**: 内容角度分类+质量约束
